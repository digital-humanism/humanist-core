# Contributing to humanist-core

Thank you for considering contributing!

## Before you start

- Read the [Manifesto](https://github.com/digital-humanism/manifesto) and `ARCHITECTURE.md`
- Open an issue to discuss significant changes before writing code

## Pull request process

1. Fork the repository
2. Create a feature branch
3. Write code with English comments and docstrings
4. Follow the existing style
5. Submit a pull request

## Contributor License Agreement

By submitting a pull request, you agree to the terms of the [CLA](CLA.md).
Please include the following line in your first pull request description:

> I have read and agree to the Contributor License Agreement.
